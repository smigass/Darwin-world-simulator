# Darwin World Simulator
---
## Project Description
Darwin World Simulator is a simulation inspired by Darwin's theory of evolution. The project simulates a world where organisms compete for resources, reproduce, and evolve in response to changing environmental conditions. 

This project was created as part of a course on Object-Oriented Programming at the Faculty of Computer Science, AGH University of Science and Technology.

## Features
- Simulation of an environment with diverse organisms.
- Evolutionary mechanisms such as mutations and natural selection.
- Ability to adjust simulation parameters, such as world size, number of organisms, and resource availability.
- Visualization of the simulation process.

## Technologies
- Programming language: Java
- Libraries: JavaFX
